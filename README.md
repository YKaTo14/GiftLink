# GiftLink

GiftLink is a lightweight capstone submission scaffold for a marketplace that helps people give away household items they no longer need.

Included deliverables:
- `user-story.md`
- `db.js`
- `giftRoutes.js`
- `searchRoutes.js`
- `authRoutes.js`
- `RegisterPage.js`
- `LoginPage.js`
- `mainpage`, `register`, `login`, `item_detail`, `search_item`
- `inserted_items`
- `CI/CD`
- `deploymentURL`
- `userstories.png`
- `deployed_landingpage.png`
