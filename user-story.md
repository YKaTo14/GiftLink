# GiftLink User Stories

## Template

As a user, I want to give away items I no longer need so that someone else can reuse them.

As a visitor, I want to search by category so that I can quickly find items I need.

As a registered user, I want to log in securely so that I can manage my listings.

As a user, I want to update my profile so that my contact details stay current.

As a visitor, I want to view item details so that I can decide whether to request an item.

As a donor, I want to see clear item status so that I know whether an item is available.

As a user, I want to post new items quickly so that sharing remains simple.

As an admin, I want to review reports so that the marketplace stays safe and organized.
